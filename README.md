# 🛡️ ShieldGateway - Reverse Proxy & Distributed Rate Limiter

[![Java](https://img.shields.io/badge/Java-21-orange.svg)](https://jdk.java.net/21/)
[![Spring Boot](https://img.shields.io/badge/Spring%20Boot-3.3-green.svg)](https://spring.io/projects/spring-boot)

O **ShieldGateway** é um API Gateway e Proxy Reverso de alta performance construído com **Java 21** e **Spring Boot 3**, alavancando **Virtual Threads (Project Loom)**.

## 🚀 Como Executar
Abra a pasta no IntelliJ IDEA ou VS Code e rode a classe `ShieldGatewayApplication.java`.
